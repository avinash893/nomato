# Agent Guidelines & Permissions

## Permissions & Autonomy
- **Full Autonomous Editing**: Antigravity IDE has full authorization to create, modify, refactor, and delete files across the entire workspace (frontend, services, configurations, dependencies).
- **Proactive Execution**: Directly execute commands, build projects, restart background processes, run tests, and verify outcomes without unnecessary confirmation.
- **End-to-End Problem Solving**: When a feature or fix is requested, implement the complete solution across backend and frontend, verify compilation, test in the browser, and ensure everything runs smoothly.

## Code Standards
- **Clean TypeScript/JavaScript**: Type-safe, modular, and maintainable structure.
- **Modern UI & UX**: Rich styling, responsive layouts, and seamless user interaction.
- **Accurate Geolocation & Services**: Clean English formatting, precise coordinate/pincode handling, robust fallbacks.
